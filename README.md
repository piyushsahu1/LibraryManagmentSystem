# Library Management System

## Overview

Library Management System is a web-based application developed using Spring MVC and Hibernate. It helps manage library books by providing operations such as adding, viewing, searching, updating, issuing, and returning books.

## Features

* Add Book
* View All Books
* Search Book
* Update Book Details
* Delete Book
* Issue Book
* Return Book

## Technologies Used

### Backend

* Java
* Spring MVC
* Hibernate

### Frontend

* JSP
* HTML
* Bootstrap

### Database

* MySQL

### Build Tool

* Maven

### Server

* Apache Tomcat

## Project Structure

* Controller Layer
* Service Layer
* DAO Layer
* Entity Layer
* View Layer (JSP)

## How to Run

1. Clone the repository.
2. Configure MySQL database settings in `hibernate.cfg.xml`.
3. Build the project using Maven.
4. Deploy the WAR file on Apache Tomcat.
5. Open the application in your browser.
